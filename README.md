> A curated list of awesome services, platforms, and tools for building, hosting, and managing static websites.

Static websites are fast, secure, and easy to maintain. This list includes services that enable developers, marketers, and content creators to deploy static websites with ease.

## Hosting Platforms

- [Netlify](https://www.netlify.com/) – Hosting with CI/CD, functions, forms, and more.
- [Vercel](https://vercel.com/) – Optimized for Next.js and Jamstack deployments.
- [Cloudflare Pages](https://pages.cloudflare.com/) – Fast, secure, and global static site hosting.
- [GitHub Pages](https://pages.github.com/) – Free hosting directly from your GitHub repositories.
- [Surge](https://surge.sh/) – Simple command-line deployment for static sites.
- [Render](https://render.com/) – Modern static site hosting and backend services.
- [Firebase Hosting](https://firebase.google.com/products/hosting) – Google-backed static site hosting with CDN.
- [GitLab Pages](https://docs.gitlab.com/ee/user/project/pages/) – Static site hosting from GitLab repositories.

## CMS for Static Sites

- [Netlify CMS](https://www.netlifycms.org/) – Git-based CMS for static sites.
- [TinaCMS](https://tina.io/) – Inline editing and Git-backed content for static sites.
- [Forestry](https://forestry.io/) *(archived)* – Visual CMS for Jekyll and Hugo.
- [CloudCannon](https://cloudcannon.com/) – CMS with live editing for static site generators.
- [Publii](https://getpublii.com/) – Desktop CMS for static websites.

## Static Site Generators

- [Jekyll](https://jekyllrb.com/) – Blog-aware static site generator written in Ruby.
- [Hugo](https://gohugo.io/) – Fast, flexible static site generator in Go.
- [Gatsby](https://www.gatsbyjs.com/) – React-based SSG with GraphQL support.
- [Next.js](https://nextjs.org/) – React framework with static generation and SSR.
- [Eleventy](https://www.11ty.dev/) – Simpler, flexible SSG written in JavaScript.
- [Astro](https://astro.build/) – Build faster websites with less JavaScript.

## CI/CD & Deployment

- [GitHub Actions](https://github.com/features/actions) – Automate deployments and tests.
- [Netlify CLI](https://docs.netlify.com/cli/get-started/) – Deploy sites from your terminal.
- [Vercel CLI](https://vercel.com/docs/cli) – Command-line tools for deployments.
- [Cloudflare Wrangler](https://developers.cloudflare.com/workers/wrangler/) – Deploy projects to Cloudflare.
- [Surge CLI](https://surge.sh/help/getting-started-with-surge) – Easy terminal deployments.

## Form Handling

- [Formspree](https://formspree.io/) – Simple form backend for static sites.
- [Netlify Forms](https://docs.netlify.com/forms/setup/) – Built-in form handling.
- [Formsubmit](https://formsubmit.co/) – Free and easy contact form backend.
- [FormKeep](https://formkeep.com/) – Form backend with spam protection and integrations.
- [StaticForms](https://www.staticforms.xyz/) – Form backend for HTML sites.
- [Simple Signups](https://simple-signups.com/) – Form backend for static and dynamic sites.

## Comments & Search

- [Giscus](https://giscus.app/) – Comments via GitHub Discussions.
- [Utterances](https://utteranc.es/) – Lightweight GitHub-based comments.
- [Disqus](https://disqus.com/) – Popular third-party comment system.
- [Algolia DocSearch](https://docsearch.algolia.com/) – Search-as-a-service for docs.
- [Pagefind](https://pagefind.app/) – Static site search without JavaScript frameworks.

## E-Commerce

- [Snipcart](https://snipcart.com/) – Add a shopping cart to any static site.
- [Shopify Buy Button](https://shopify.dev/custom-storefronts/buy-button-js) – Embed Shopify into static sites.
- [Foxy.io](https://www.foxy.io/) – Customizable e-commerce for any site.

## Analytics

- [Plausible](https://plausible.io/) – Simple, privacy-friendly analytics.
- [Umami](https://umami.is/) – Open-source analytics.
- [GoatCounter](https://www.goatcounter.com/) – Lightweight web analytics.
- [Fathom](https://usefathom.com/) – Privacy-focused, GDPR-compliant analytics.

## Miscellaneous Tools

- [StaticGen](https://www.staticgen.com/) – SSG directory by Netlify.
- [Jamstack.org](https://jamstack.org/) – Learn more about the Jamstack ecosystem.
- [SVGO](https://github.com/svg/svgo) – SVG optimizer for reducing file size.
- [ImageOptim](https://imageoptim.com/mac) – Compress images for web performance.
